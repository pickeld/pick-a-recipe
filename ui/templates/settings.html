AI Extraction

Which of the providers above turns raw video and page content into a structured recipe. It also reads on-screen text and picks the dish photo, so it needs a model that can see images.

Nutrition lookup

Optional live USDA FoodData Central search when an ingredient is missing from the local table. Leave blank to use the local table only. The USDA_FDC_API_KEY environment variable is used if this field is empty.

Get a free key at fdc.nal.usda.gov/api-key-signup.html. The key is stored in this instance's database, never in source code.

Recipe Language

Speech to Text

Turning the video's audio into text. Whisper runs on this server and needs no API; a provider transcribes over the network instead, which is faster on a small machine.

Larger models are more accurate but slower. 'Small' is recommended for mixed-language content.
Optional, and not an AI provider key: it only downloads the Whisper weights faster and at a higher rate limit. Get one at huggingface.co/settings/tokens.
Only providers with an OpenAI-compatible audio endpoint can transcribe.
For example whisper-1, gpt-4o-transcribe or whisper-large-v3.
If the provider fails, the job falls back to Whisper on this server rather than losing the audio.
